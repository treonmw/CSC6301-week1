Ricks Rolling Ruckus
Description: Rick's Rolling Ruckus is a python rolling dice program that allows the user to roll different types of dices. The program supports d4, d6, d8, d10, d12, and d20 dice.
The program asks the user which type of dice they would like to roll and from there validates the input. From the input it will display the results and allow the user to continue playing with only valid results.
Development Environment:
PL - Python 3
IDE - VS Code
OS - Windows

Files:
GenericDice.py - contains dice rolling function and program
Documentation - Generated pydoc HTML documentation

How to Run:
Open terminal in the project directory and run GenericDice.py

The program will ask the user which type of dice they would like to roll and will continue to keep asking the user if they want to continue after displaying the results.
